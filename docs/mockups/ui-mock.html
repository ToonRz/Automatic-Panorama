Stateless v1 · no database, no stored uploads Design notes ↓

Palette

Dark-committed. The app is an optical instrument, read in a lecture hall with the lights down.

ground panel aqua amber coral

Type

Fraunces for display, DM Sans for prose, JetBrains Mono for every number, code, and label.

  • Measurements are always mono and tabular so columns line up.
  • Uppercase mono labels carry 0.12em tracking.

Rules this mock encodes

  • Aqua means accepted, amber means running, coral means rejected. No other use.
  • Every failure names the pair, the measured value, and the threshold it missed.
  • Diagnostics are part of the result, not a debug panel.
  • Nothing on the success screen is reachable before the backend returns 200.

Still to decide

  • Drag-to-reorder frames, or trust the server's ordering?
  • Side-by-side match visualization as a second tab.
  • Mobile layout: the canvas stacks under the rail below 900px.
