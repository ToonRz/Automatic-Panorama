ไอเดียการประยุกต์ใช้ Sankey Flow UI ในโปรเจค Automatic-Panorama

UI สไตล์ Sankey / Flow Diagram แบบนี้เหมาะกับระบบ Computer Vision Pipeline อย่างยิ่ง! เพราะกระบวนการต่อภาพพาโนรามาคือกระบวนการ "คัดกรองจุด (Keypoint Survival & Inlier Filtering)" และ "การประกอบภาพ (Pairwise Graph Flow)" จากพันๆ จุดจนเหลือเฉพาะ Inliers ที่คำนวณ Homography สำเร็จ

1. Feature Survival Funnel (แนะนำ ⭐) กำลังแสดง

แสดงว่าแต่ละรูป (Img 1, 2, 3) สกัด Keypoints ได้เท่าไหร่ → กรอง Lowe's ratio test เหลือเท่าไหร่ → RANSAC คัด Inliers ที่รอดไปคำนวณ Homography เท่าไหร่ (ตอบคำถามว่าทำไมบางรูปต่อไม่ติด)

2. Pairwise Graph & Canvas Flow สลับดูได้

แสดง Flow ของคู่ภาพ (Pairs 1-2, 2-3) → การจับคู่เข้า Reference Anchor Frame → พื้นที่ Pixel ที่ถูก Warp ไปทับบน Canvas พาโนรามาสุดท้าย

3. Pipeline Latency Breakdown สลับดูได้

แสดงเวลาประมวลผล (ms): จาก Image Load → SIFT Feature Extraction → FLANN/BFMatcher → RANSAC H → Warping & Multi-band Blending
