# Task 09b - memory budget on 512 MB

- Owner: TBD
- Reviewers: TBD (CV core) and ToonRz (deploy compatibility)
- Depends on: none
- Spec: `docs/deployment-plan.md` section 7, D-005, D-006

## Scope

Prove that the worst request the production settings accept fits the Render
Free instance, and tighten the settings in the agreed order if it does not.
The output is a reproducible measurement, not a guess.

## Files

- `backend/scripts/measure_peak_memory.py` - new; generates the worst accepted
  request synthetically and posts it to a running backend
- `docs/deployment-plan.md` - section 7 results
- `render.yaml` and `backend/app/core/config.py` - only if a limit changes
- `backend/app/tests/` and `frontend` contract snapshots - only if a limit
  changes (`make contract-snapshots`)

## Method

1. Build a Python 3.12 image of `backend/` with the same install and start
   command as `render.yaml`.
2. Run it with `--memory=512m --memory-swap=512m` and the `render.yaml`
   environment.
3. Post the worst accepted request: `MAX_UPLOAD_FILES` synthetic frames at the
   largest decoded size `MAX_IMAGE_PIXELS` and `MAX_TOTAL_UPLOAD_MB` allow.
   The frames are generated by the script; no photo is committed.
4. Read the peak from the container's cgroup `memory.peak`.
5. Repeat for the normal path: three budget-sized frames.
6. Repeat each run three times and record the highest peak.

## Acceptance

- [ ] the script and the exact commands are committed, and a second person can
      reproduce the numbers;
- [ ] section 7 of `docs/deployment-plan.md` records the peak for both requests,
      the settings used, and the image and Python versions;
- [ ] the worst accepted request peaks at or below 410 MB, and the container is
      not OOM-killed;
- [ ] if a limit had to change, the order was `MAX_OUTPUT_PIXELS`, then
      `MAX_UPLOAD_FILES`, then `INPUT_LONG_EDGE_CAP`, each change is recorded
      with its measured peak, `render.yaml` and the config defaults agree, and
      the `/api/v1/config` contract snapshots are regenerated;
- [ ] if the peak is dominated by something those three settings do not
      control, the finding is recorded here and brought to ToonRz for a
      decision before any other setting changes;
- [ ] `make test` and `make lint` are green.
